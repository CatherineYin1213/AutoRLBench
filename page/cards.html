RL training fails quietly.

Reward curves look healthy. Held-out accuracy dies. Training reward climbs while generation collapses. A single eval returns 6.7% instead of 20% — but it's the sampling protocol, not the model.

These failures don't show up in standard benchmarks. We're building the dataset of them.

02 · The problem
Why it's hard
RL failures are quiet.

Training reward looks fine. Held-out accuracy quietly dies. Standard benchmarks don't measure this.

What the logs show What's actually wrong
Training reward ↑ steadily Length bonus — policy learns to write longer, not better
Search & format rates ~1.0 Zero query vector — every search returns the same docs
Training reward ↑, same policy GRPO → REINFORCE — uid assigned after rollout repeat; group baseline disappears
One low AIME25 score Protocol bug — 1 sample/question; noisy reward

The six tasks in v0.1, one per domain:

  • 🔁 Reward — length bonus teaches the policy to write longer, not better
  • ⚙️ Config — 1 sample/question on 30-question AIME; noise, not a training failure
  • 📊 Data — VERY_HARD train / EASY eval; held-out ends below step 0
  • 🌐 Environment — query vector all zeros; every search returns the same docs
  • 🧮 Algorithm — uid assigned after rollout repeat; GRPO becomes REINFORCE
  • 🛠 Infrastructure — rewritten monkey patch drops the flash-attention hook silently

Each one took a real run to discover.
