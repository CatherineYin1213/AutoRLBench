The rule

Two levels

Issue is a diagnosis. Solution is that same diagnosis plus a run that applies the fix. We turn either one into the task.

Level 01Issue

05 / BEFORE YOU PUBLISH

Run the same checks the catalog will run.

Resolve every structural error locally, then exercise both evaluation levels with a known-good fixture.

  1. 01
    Freeze the case

    Capture the workspace, environment, configuration, logs, and held-out evidence.

  2. 02
    Write the contracts

    State the action, constraints, deliverables, and scoring behavior in each instruction.

  3. 03
    Validate and exercise

    Run the structural validator and test each verifier against a known result.

Structural validation
PYTHONDONTWRITEBYTECODE=1 \
python3 -m autorlbench validate path/to/your_task
